Room to play.

A small taste of the development loop.

Each lesson recognizes a few editable values in an ordinary Swift example. Change those values and run it to update the browser preview. You can explore a counter, a form event, and Boolean state without installing anything.

This page doesn’t execute Swift, contact a server, or render arbitrary templates. The surrounding program stays fixed. Unsupported edits show guidance and keep the working preview; running valid edits resets state. Your drafts stay in this tab until you reload.

Take it into the local Roost Playground +

Download the Swift file and run it from a configured Roost Playground checkout: 

./playground /path/to/Counter.swift

The local playground uses the real Swift compiler and ESW Live. Edit and save to rebuild; compiler errors leave the previous app running. Successful reloads reset state.

That companion project currently requires macOS 15+, Swift 6.3+, and the local Roost, ESW Live, and Nexus checkouts. It has not been published as a standalone release yet.
